# Gerenciador de Tarefas

Projeto desenvolvido em Python para a prática de programação e utilização do GitHub.

## Funcionalidades

- Adicionar tarefas.
- Listar tarefas cadastradas.
- Concluir tarefas.
- Excluir tarefas.

## Tecnologias utilizadas

- Python
- Git
- GitHub

## Objetivo

Desenvolver uma aplicação simples para organizar tarefas e praticar conceitos de programação, versionamento de código, branches, commits, issues e pull requests.
